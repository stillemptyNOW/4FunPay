# Происхождение кода

**4FunPay** — форк открытого проекта **FunPayCardinal**.

| | |
|---|---|

| Репозиторий | https://github.com/sidor0912/FunPayCardinal |

Значительная часть кода этого репозитория, включая пакет `FunPayAPI`
(слой взаимодействия с funpay.com), ядро `cardinal.py`, обработчики событий
`handlers.py` и панель управления `tg_bot/`, происходит из FunPayCardinal.

## О лицензии

На момент снятия форка в исходном репозитории **отсутствовал файл лицензии**
(GitHub API возвращал `"license": null`, файлов `LICENSE`/`COPYING` в дереве
не было). Это означает, что автор не предоставил публичного разрешения на
распространение и модификацию — стандартных лицензионных условий, которым
можно было бы «просто следовать», здесь не существует.

Этот файл сохранён как указание на происхождение кода. Он не является
лицензией и не заменяет её.

Если ты планируешь публиковать этот форк, продавать доступ к нему или
предлагать его как услугу — разберись с правовой стороной отдельно.
Приватное использование на своём сервере и публичное распространение —
разные ситуации.

## Что изменено относительно исходного проекта

Список правок ведётся в истории git. Ключевые отличия, влияющие на поведение:

- удалён модуль `announcements.py`, который каждые 600 секунд опрашивал
  GitHub Gist исходного автора и отображал полученный текст, изображения и
  инлайн-клавиатуру с произвольными ссылками в Telegram-чате владельца бота;
- удалён `Utils/updater.py` — самообновление скачивало архив релиза с
  репозитория исходного автора и распаковывало его поверх рабочего каталога.
  Функции резервного копирования из этого модуля сохранены в `Utils/backup.py`,
  обновление выполняется через `git pull`;
- `TGBot.edit_bot()` больше не перезаписывает имя, краткое и полное описание
  Telegram-бота владельца рекламой исходного проекта;
- имя файла исходящих изображений (`FunPayAPI/account.py`) обезличено: раньше
  оно содержало название исходного проекта и уходило на серверы FunPay,
  где было видно покупателю;
- все ссылки на Telegram-каналы, чаты и донат-реквизиты исходного автора
  заменены плейсхолдерами, заполняемыми в `branding.py`;
- удалён `.github/FUNDING.yml` с донат-реквизитами исходного автора.
